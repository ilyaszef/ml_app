# ML Studio

Application Streamlit de préparation de données, visualisation, apprentissage supervisé et optimisation de modèles.

## Installation et lancement

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Importez un fichier CSV, Excel ou JSON, puis suivez les étapes du menu latéral.

⚠️ Note : ne lance pas `import io.py` avec `python`. En cas de besoin, exécute uniquement : `streamlit run app.py`.
